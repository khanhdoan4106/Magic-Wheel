    How to use

    Everything is typed straight into the Entries box. Short codes at the end of a line change how likely that name is to win.

    1. Add names

    Write one name per line in the Entries tab. The wheel updates as you type.

    Alex
Minh Anh
Jordan

    2. Spin

    Press Spin, click the wheel, or press Space / Enter when you are not typing. The flapper at the top picks the winner.

    3. Handle the winner

    In the result window choose Remove from wheel, Spin again or Copy. Press Esc to close.

    Two modes

    Normal gives every name the same chance; any *N or N% codes are ignored. Cheat opens an odds table where you pick each name's chance (Auto, 0%, 5%, 10% … 100%), or type the codes yourself. Switch in Settings → Mode, or quietly with Alt + Shift + C. The page looks the same in both modes, so viewers can't tell which one is on.

    *N Weight multiplier · Cheat mode

    Add *N to the end of a line to make that name N times more likely than a normal name. Its slice on the wheel grows to match, so everyone can see the advantage.

    Alex
Jordan *3     ← 3× Alex's chance
Sam *0.5      ← half Alex's chance

    N% Fixed chance · Cheat mode

    Add a percentage to lock that name's chance of winning. 100% means it always wins. The other names share whatever is left. The wheel still looks even unless you turn on Show real odds on wheel.

    Alex
Jordan 70%    ← wins 70% of spins
Sam           ← shares the other 30%
Taylor 100%   ← always wins

    Rules for odds

    • A line can use *N and N% together; the percentage wins.
    • If percentages add up to 100% or more, only those names can win, scaled to their shares.
    • 0% means the name never wins but stays on the wheel.
    • The odds table in Settings (Cheat mode) lets you pick a preset chance for any name from a dropdown and shows everyone's real chance. It writes the N% code into the list for you.

    Elimination mode

    Turn it on in Settings to remove each winner automatically. Good for calling people one by one.

    Several winners at once

    Set Winners per spin in Settings. One press spins the wheel N times and never picks the same person twice in that round.

    Split into teams

    Open the Teams tab, pick how many teams, press Split randomly, then Copy to paste the result anywhere.

    Save lists

    Name the current list and press Save list. Open it again later with one click. Saved lists and history stay in this browser only.

    Tidy the list

    Shuffle, Sort A–Z and Remove duplicates keep the list clean. Start a line with # to keep a name but leave it off the wheel.

    Look and feel

    Change spin duration, sound, confetti, light or dark appearance and the color palette in Settings.
